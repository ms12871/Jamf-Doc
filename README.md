# Apple Fleet Management Fieldnotes

A standalone study hub for learning Jamf Pro and managing Apple device fleets. It collects links to official documentation, courses, community resources, and practical tools in one searchable page.

## What it covers

- Jamf Pro administration, training, APIs, marketplace, and Jamf Nation
- Apple Business and Apple Business Manager, Automated Device Enrollment, MDM, and Declarative Device Management
- Mac fleet security, software updates, packaging, and update workflows
- Community resources and useful VS Code extensions

## Public URL

https://ms12871.github.io/Jamf-Doc/

## Open the page

Open [`index.html`](index.html) directly in a browser. The page has no build step or external dependencies. Use the search field and category filters to find resources. Links open the reference publisher’s site.

## VS Code recommendations

The `.vscode/` folder contains workspace extension recommendations for Markdown, YAML, REST API testing, and shell formatting. VS Code may offer these extensions when the workspace is opened. The folder is excluded from Git by [`.gitignore`](.gitignore), so those local recommendations are not included in commits.

References are maintained by their publishers and can change over time. Check the linked documentation for current product names, requirements, and procedures.
